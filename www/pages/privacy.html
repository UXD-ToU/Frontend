To.U 개인정보처리방침

시행일: 2026년 11월 7일

박영서(이하 “운영자”)는 To.U(패키지명: com.to.u.app)의 개인정보 처리 방식을 다음과 같이 안내합니다. 본 방침은 AI 분석 기능을 제공하지 않는 현재 버전에 적용됩니다.

1. 처리하는 정보와 목적

  • 친구 이름, 생일, 관계 및 프로필 단추 색상: 친구 관리와 생일 표시
  • 나만의 또는 친구별 위시리스트의 상품명, 브랜드, 가격, 메모, 상품 링크, 사용자가 선택한 상품 사진: 선물 후보 저장 및 조회
  • 사용자가 ‘붙여넣기’를 눌렀을 때 클립보드의 텍스트: 상품 링크 입력
  • 이메일 문의 시 발신자 이메일 주소와 문의 내용: 문의 확인과 답변

현재 앱은 회원가입이나 로그인을 요구하지 않으며, 연락처 목록을 불러오거나 생일 알림을 발송하지 않습니다. 사진·링크를 AI로 분석하지 않습니다. 다른 사람의 정보나 사진을 입력할 때에는 필요한 범위에서 적법하게 이용해 주세요.

2. 저장 및 외부 전송

친구 정보와 위시리스트는 기기 내 앱 저장소(IndexedDB)에 저장됩니다. 초기 실행 상태를 기록하기 위해 localStorage를 사용합니다. 선택한 사진은 기기에서 크기를 조절해 저장합니다. 이 관리 데이터를 운영자 서버로 업로드하거나 계정과 동기화하는 기능은 없습니다.

현재 앱은 Gemini, Groq, NAVER Shopping 등 상품 분석·검색 API에 입력 정보, 사진 또는 링크를 전송하지 않습니다. 광고·사용자 행동 분석 SDK를 포함하지 않습니다.

3. 외부 연결과 제3자 서비스

  • 글꼴 제공: 앱은 Pretendard 글꼴을 jsDelivr CDN에서 불러옵니다. 이 과정에서 IP 주소, 접속 시각, 브라우저·기기 관련 요청 정보가 해당 서비스에 전달될 수 있습니다. 친구 정보, 메모, 상품 사진은 글꼴 요청에 포함하지 않습니다. 서비스 제공자의 서버 위치에 따라 국외에서 처리될 수 있습니다. jsDelivr 개인정보처리방침
  • 상품 사이트: 사용자가 상품 사이트 링크를 열면 해당 사이트에 연결되며, 그 사이트의 개인정보처리방침이 적용됩니다.
  • 문의: 문의 이메일은 운영자가 사용하는 Gmail을 통해 처리됩니다. 사용자가 보낸 이메일 주소와 문의 내용은 메일 서비스에 저장·처리될 수 있습니다. Google 개인정보처리방침
  • 방침 웹페이지: 공개된 개인정보처리방침을 열면 웹 호스팅 제공자인 GitHub Pages가 접속 IP 등 요청 정보를 처리할 수 있습니다. GitHub 개인정보처리방침

운영자는 기기에 저장된 친구·위시리스트 정보를 판매하거나 광고 목적으로 제공하지 않습니다. 외부 서비스의 접속 정보 보관·삭제는 각 서비스의 정책에 따릅니다.

4. 보관과 삭제

기기에 저장된 정보는 사용자가 해당 친구 또는 선물 후보를 삭제하거나 Android 설정에서 앱 저장 데이터를 삭제할 때까지 보관됩니다. 친구를 삭제하면 해당 친구의 선물 후보도 삭제됩니다. 앱 삭제 시 일반적으로 앱 데이터가 삭제되지만, Android의 백업·복원 설정에 따라 데이터가 복원될 수 있습니다. 기기 백업도 필요한 경우 별도로 관리해 주세요.

문의 이메일은 답변 및 후속 처리가 완료되어 보관 목적이 끝나면 삭제합니다. 관련 법령에 따라 보관이 필요한 경우에는 해당 기간 동안 보관합니다. 이미 기기에 내려받은 정보나 외부 서비스가 처리한 정보의 삭제는 각각의 저장 위치와 서비스에 따라 달라질 수 있습니다.

5. 기기 기능과 접근

상품 사진은 사용자가 사진 선택 창에서 직접 고릅니다. 클립보드는 ‘붙여넣기’를 누를 때 읽으며, 지속적으로 감시하지 않습니다. 앱은 현재 연락처·위치·마이크에 접근하거나 알림 권한을 요청하지 않습니다. 운영체제에서 접근 허용 여부를 묻는 경우 사용자가 선택할 수 있습니다.

6. 이용자의 선택과 보호 조치

사용자는 앱에서 친구 정보를 조회·수정·삭제하고 선물 후보를 조회·삭제할 수 있습니다. 앱 저장 데이터를 삭제하면 전체 로컬 데이터를 지울 수 있습니다. 운영자는 로컬 데이터를 원격으로 열람·복구·삭제할 수 없으므로 기기 내 삭제는 사용자가 직접 진행해야 합니다.

앱은 기기의 앱 저장 영역을 사용하며, 글꼴 등 앱이 지정한 외부 리소스는 HTTPS로 요청합니다. 기기 잠금 및 운영체제 업데이트를 통해 기기 접근을 관리해 주세요. 외부 링크의 보안은 연결되는 사이트에 따라 달라집니다.

8. 방침 변경

처리 방식이 변경되면 이 페이지와 앱의 개인정보처리방침에 변경 내용을 안내합니다. AI 기능을 도입하는 경우 실제 전송 항목, 제공업체, 목적, 보관·삭제 및 국외 처리 사항을 확정해 방침을 갱신하고 필요한 안내·동의를 제공한 뒤 적용합니다.
